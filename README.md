# Mr. Mata Learning Hub

A dark, Matrix-inspired learning games hub for secondary computer science students.

## Games

- **Algorithms**
  - Bubble Sort Lab
  - Search Sprint, coming soon
- **Data Representation**
  - Binary Builder
- **Logic**
  - Logic Gates, coming soon

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The app is built with Vite and deploys as a static site.
